# Independent study concept

## Problem Statement
A memory writer may finish a native effect and disappear before its enclosing operation acknowledges completion. Its successor then faces an ordinary delivery ambiguity: resubmit the event, trust an incomplete acknowledgement trail, or inspect already committed state. A content-presence test addresses only part of this situation. Different physical representations can encode the same facts while exposing different evidence to a later query. The proposed article examines that boundary with public implementations and conversational workloads, rather than reconstructing a proprietary application.

## Core Hypothesis
Recovery conformance should be assessed at multiple layers. Preserved source facts do not imply unchanged storage multiplicity, ordered context, or task behaviour. The candidate contribution is a reproducible operational-to-decision trace and a decomposition useful for evaluation. Duplicate handling and retrieval statistics are established subjects; this work does not propose a new mathematical principle or promise a breakthrough.

## Technical Concept
Let a logical event carry a stable occurrence identifier, a body and a logical timestamp. Its repeated delivery retains that identity. A genuinely later observation receives a new identifier even when its wording repeats. Physical memory points have separate addresses and a mapping back to their source occurrences. The fact projection of a physical multiset can remain constant when a copy is appended. An ordered, budgeted retrieval function need not be invariant under that same transformation.

This distinction motivates three contracts. Storage conformance asks whether effects and physical cardinality match the declared replay policy. Evidence conformance asks whether the query selects the intended occurrences within a bounded context. Task conformance asks whether the reader produces the required answer from the permitted evidence. They should be reported separately. Stochastic reader wording is not a reliable proxy for a changed task decision, and agreement between two observed runs is not universal determinism.

A second distinction concerns index statistics. A retriever can score a point using information computed across other physical points. Deleting duplicate entries from the final list therefore need not reconstruct the ranking that existed before their ingestion. Native hybrid score components make this question inspectable. An intervention that restores only the clean statistics while leaving duplicate points searchable can localize mediation, provided it is explicitly identified as a diagnostic using otherwise unavailable clean-state information. Classical inverse-document-frequency sensitivity is an antecedent to this interpretation, not its novelty claim.

## Approach and Controls
Use the released LoCoMo and full cleaned LongMemEval-S histories as fixed public sources. Historical participant inputs exclude questions, answer annotations and evaluator labels. Stable occurrence IDs distinguish delivery replay from independent corroboration. Preserve the native baseline's physical IDs before cloning interventions so that a changed random address allocation does not masquerade as an observed effect.

Run local Mem0 raw ingestion and persistent LlamaIndex retrieval as separate native participants with real public embeddings. They are operational examples rather than complete reproductions of inferred-memory defaults or hosted products. Compare native replay, authored occurrence admission, literal-content admission and retrieval-time event collapse. Content equality is a deliberately different identity policy and can suppress legitimate fresh observations. The sequential controls do not claim atomic uniqueness against concurrent writers.

Collect blinded reader prompts through the requested Sol alias and a pinned local Qwen model. Reuse archived responses when entire prompt bytes match; expose those aliases instead of counting them as additional observations. No-context and gold-support inputs serve distinct diagnostics. Gold-support selection is an oracle, not a deployed competitor. Preserve malformed answers, invalid citations, disagreement, failures and unknown labels. No model training, optimizer or new embedding architecture is introduced.

## Evidence and Interpretation
The separate experimental log supplies every measured quantity and raw-artifact pointer. The main article should explain the strongest directly inspectable trace, then show the full intervention table, ordinary variability controls and any gains or null results. A post-hoc example illustrates a mechanism and does not enlarge the sample. Native score diagnostics must retain their exploratory timing and local scope. Distinguish technical queries, physical model requests, condition aliases, repeated decisions and underlying source histories.

The current calibration limitations, same-family automated judge and lack of outside human review must remain prominent. Source overlap prevents a naive independent-question interpretation. A meaningful journal claim requires defensible novelty relative to close duplicate-evidence studies, suitable confirmation and independent expert scrutiny. Neither extra citations nor more execution cells supplies those properties by itself.
